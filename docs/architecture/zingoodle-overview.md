# Zingoodle Overview

## What Zingoodle Is

Zingoodle is a long-term personal systems laboratory focused on mastering Data Structures & Algorithms (DSA) and low-level systems programming from first principles. It serves as a personal learning repository to develop deep systems thinking, first-principles reasoning, and disciplined problem-solving skills.

## What Zingoodle Is Not

- A production codebase or library
- A framework or tool for others
- Optimized for speed, hype, or external consumption
- A collection of tutorials or courses

## How DSA and Systems Relate

- **DSA Domain**: Provides the algorithmic foundation and data structure knowledge needed for systems programming.
- **Systems Domain**: Applies DSA concepts in real systems contexts, exploring how algorithms behave under constraints like memory limits, concurrency, and I/O.
- Together, they form a complete learning loop: theory (DSA) informs practice (systems), and practice reveals gaps in theory.

## Domains

- `zingoodle-dsa/`: Clean implementations, problems, and analysis
- `zingoodle-systems/`: Multiple isolated systems, each answering one fundamental question
- `experiments/`: Scratch space for exploration
- `docs/`: Invariants, specs, postmortems, and architecture

## Cultural Laws

- Invariants over features
- First-principles rule
- Build → Break → Document
- One system = one question
- No magic rule
- Longevity mindset
