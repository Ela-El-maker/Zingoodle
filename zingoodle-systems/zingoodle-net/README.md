# Zingoodle Net

## Purpose

Implements networking fundamentals, including TCP/UDP protocols from scratch.

## Question Answered

How can we send and receive data over networks reliably and efficiently?

## Invariants

- Data delivery guarantees (where applicable)
- Connection state management
- Packet integrity and ordering
- Address resolution correct
- Congestion control effective

## Non-Goals

- High-level protocols (HTTP, etc.)
- Wireless networking
- Security features like TLS
- Distributed systems coordination

## Failure Modes

- Packet loss or corruption
- Network congestion
- Connection failures
- Routing issues
